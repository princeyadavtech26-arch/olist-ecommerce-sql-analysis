# 🛒 Olist E-Commerce Data Analysis | SQL & MySQL

## 📌 Project Overview

This project focuses on analyzing **Olist e-commerce data using SQL and MySQL** to understand customers, orders, payments, products, and sales performance.

The main objective is to transform raw e-commerce data into meaningful business insights and answer real-world business questions using SQL.

---

## 🎯 Business Problem

E-commerce businesses generate large amounts of data from customers, orders, products, and payments.

This analysis helps understand:

- Customer purchasing behavior
- Order patterns
- Sales performance
- Payment preferences
- Product and category performance
- Trends over time

---

## ❓ Business Questions

The project focuses on questions such as:

- How many customers are present in the dataset?
- How many orders have been placed?
- What is the total sales/revenue?
- What is the average order value?
- How do orders change over time?
- Which product categories receive more orders?
- Which payment methods are used most frequently?
- How do customers use different payment types?
- Which customers contribute more to sales?
- What patterns can be identified from orders and payments?
