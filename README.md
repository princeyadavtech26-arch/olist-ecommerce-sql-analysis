# 🛒 Olist E-Commerce Data Analysis | SQL & MySQL

## 📌 Project Overview

This project focuses on analyzing **e-commerce sales data using SQL and MySQL**.  
The goal is to transform raw transactional data into meaningful business insights related to customers, orders, products, payments, and sales performance.

The project demonstrates practical SQL skills such as data exploration, filtering, aggregation, grouping, joins, and business-oriented analysis.

---

## 🎯 Business Objectives

This analysis aims to answer questions such as:

- How many customers and orders are present?
- What are the total sales and order values?
- Which products/categories perform better?
- Which customers generate higher revenue?
- How do sales vary over time?
- What are the different payment methods used?
- What are the order and payment patterns?
- Which areas require further business investigation?
